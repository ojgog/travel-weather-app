# Pogodowy Planer Podróży

Prosta aplikacja webowa do sprawdzania aktualnej temperatury w miejscu wybranym na mapie i zapisywania wybranych celów podróży na liście.

## Technologie

- JavaScript
- Vite
- Leaflet / OpenStreetMap
- Open-Meteo API

## Uruchomienie

```bash
cd travel
npm install
npm run dev
```

Otwórz adres wyświetlony przez Vite w terminalu.

Aplikacja wymaga połączenia z internetem, aby wyświetlić mapę i pobrać dane pogodowe. Lista celów jest przechowywana tylko do odświeżenia strony.
